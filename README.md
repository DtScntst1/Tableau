# 📊 Tableau Dashboards and Visualizations

A collection of Business Intelligence (BI) dashboards built in Tableau demonstrating data storytelling and actionable insights.

## 💡 Overview
- **Objective:** Create dynamic, interactive dashboards for various business use-cases.
- **Features:** Geographic mapping, time-series analysis, drill-down capabilities, and calculated fields.

## 🛠️ Tech Stack
- **Visualization:** Tableau Desktop
- **Data Prep:** Pandas, Excel
