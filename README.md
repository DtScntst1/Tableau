A collection of Business Intelligence (BI) dashboards built in Tableau. This repository demonstrates my ability to tell stories with data, design intuitive user interfaces for stakeholders, and extract actionable business insights.

## Overview
Objective: To create dynamic, interactive, and visually appealing dashboards for various business use-cases.
Features: Geographic mapping, time-series analysis, drill-down capabilities, and complex calculated fields.
